# Мікроексперимент AI / no-AI (ЛР2)

## Мета

Порівняти дві **співмірні** чисті функції з **однаковим принципом перевірки** (case-insensitive exact equality), без висновку «AI кращий».

## Співмірні задачі (повтор 2026-11-20)

| Задача | Функція | Принцип | Режим |
| --- | --- | --- | --- |
| A | `equals_ci` | exact equality, ignore case | no-AI |
| B | `role_equals_ci` | exact equality, ignore case | AI |

Спільна специфікація (ідентична для обох):

1. Сигнатура `(left: str, right: str) -> bool`.
2. Порівняння без урахування регістру (`lower()` з обох боків).
3. Оракул: 4 кейси — рівні ігноруючи регістр; різні рядки; симетрія A/B; узгодженість між двома функціями на тих самих входах.

Жеребкування: `equals_ci` → no-AI, `role_equals_ci` → AI (зафіксовано до написання коду).

Виконання: один виконавець, послідовні блоки в одній сесії (`sequential-same-session`) — це обмеження n=1, чесно зазначене в CSV. Паралельний ізольований жереб двох людей не проводився.

`normalize_filter` + `matches_query` / `matches_category` залишаються в API (підрядок vs exact для `q`/`category`) і **не** є об’єктом порівняльного експерименту.

## Пілот (архів)

Ранні рядки з `matches_query` vs `matches_category` збережено як `pilot-dissimilar-*`: різний принцип перевірки, тому вони **не** використовуються для висновків про перевагу AI.

## Метрики

- `time_minutes` — wall-clock на реалізацію функції + оракул-тести
- `first_tests_passed` / `first_tests_total` — перший прогін оракула
- `edits_after_first` — правки після першого прогону
- `agent_test_reruns` — повторні запуски тестів агентом (N/A для no-AI)
